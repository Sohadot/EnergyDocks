# EnergyDocks.com landing page

A dependency-free conceptual and commercial landing page for EnergyDocks.com.

## Publish

Upload the contents of this directory to the root of the site. The package is ready for static hosting and GitHub Pages.

## Included

- Responsive single-page HTML/CSS/SVG experience
- SEO, canonical, Open Graph and Twitter metadata
- 1200 × 630 social preview artwork (`assets/og-image.png`)
- SVG favicon
- `robots.txt`, `sitemap.xml`, and `CNAME`

## Acquisition contact

The page routes qualified acquisition enquiries to `agent@sohadot.com`.
